# Power BI Sales Analysis Using SQL Server

## Project Overview
This project demonstrates the integration of Microsoft SQL Server with Power BI to analyze data and create interactive visual reports.

## Objectives
- Connect Power BI to a SQL Server database.
- Retrieve and analyze data from SQL Server.
- Create visualizations and dashboards.
- Present meaningful insights to support decision-making.

## Tools Used
- Microsoft SQL Server Management Studio (SSMS)
- Microsoft Power BI Desktop
- SQL

## Project Process
1. Created and prepared the database in SQL Server.
2. Connected the SQL Server data source to Power BI.
3. Imported or retrieved the required data.
4. Developed visualizations and an interactive report.
5. Analyzed the results to identify useful insights.
